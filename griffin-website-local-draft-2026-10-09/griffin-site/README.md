# Griffin Edwards — academic website

This repository contains the source for [griffin-has-questions.github.io](https://griffin-has-questions.github.io), Griffin Edwards’s academic website.

## Main content

- `_pages/about.md` — homepage and short introduction
- `_pages/teaching.html` — teaching and advising
- `_pages/research.md` — research projects and presentations
- `_pages/service.md` — service, leadership, and outreach
- `_pages/visualizations.md` — interactive mathematical visualizations
- `_pages/cv.md` — web CV
- `files/Griffin_Edwards_CV_2026.pdf` — downloadable CV
- `_data/navigation.yml` — top navigation
- `_config.yml` — site-wide contact and identity information

## Preview locally

Install the Ruby dependencies once:

```bash
bundle install
```

Then start the local Jekyll server:

```bash
bundle exec jekyll serve
```

GitHub Pages rebuilds the public site when changes are pushed to the publishing branch.
